A tiny Python program that writes one line to `/output/entry.txt`: a single line of at most 200 characters about a small good thing that happened today, written to make the reader smile. The line was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — on subject, then warmth that is genuinely felt, then surprise, then one concrete detail, then fresh wording — and then defending the winner against four fresh challengers in a revision round. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
